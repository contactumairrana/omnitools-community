Welcome to the official community hub for [**OmniTools**](https://www.devomnitools.com) — a high-performance, multilingual, 100% in-browser developer utilities platform.

> 🔒 **100% In-Browser Privacy Guarantee:**  
> Every single utility on OmniTools executes exclusively inside your local browser memory via Web Cryptography API, Canvas, and Web Workers. **Zero bytes of your sensitive tokens, passwords, database dumps, or code snippets are ever sent to an external server.**

## 🛠️ Complete Catalog of 45 Live Production Tools

### 🎨 Design & Vector Utilities
* [**QR Code Generator & Scanner**](https://www.devomnitools.com/en/tools/qr-code-generator/) — Custom center logo, Reed-Solomon error correction, WiFi/vCard payloads, vector SVG export.
* [**SVG to PNG & Vector Rasterizer**](https://www.devomnitools.com/en/tools/svg-to-png/) — 1x to 8x scale multipliers (up to 8K print quality), alpha transparency control, PNG/WebP/JPEG.
* [**CSS Flexbox Visual Playground**](https://www.devomnitools.com/en/tools/css-flexbox/) — Interactive layout builder, container alignment, child item growth factor inspector, pure CSS & Tailwind export.
* [**CSS Glassmorphism Generator**](https://www.devomnitools.com/en/tools/css-glassmorphism/) — Frosted glass visual builder with depth sliders, noise textures, and backdrop-blur.
* [**CSS Clip-Path Generator**](https://www.devomnitools.com/en/tools/css-clip-path/) — Visual polygon and geometric path builder with draggable handles.
* [**Color Contrast Checker (WCAG AAA)**](https://www.devomnitools.com/en/tools/color-contrast-checker/) — APCA and WCAG 2.1 compliance validator with color picker and contrast ratios.
* [**Color Converter & Palette Generator**](https://www.devomnitools.com/en/tools/color-converter/) — HEX, RGB, HSL, CMYK, and HSV live synchronized converter.

### 💻 Developer & Data Utilities
* [**SQL to JSON & CSV Converter**](https://www.devomnitools.com/en/tools/sql-to-json/) — Converts single and bulk multi-row `INSERT INTO` statements into JSON arrays and CSV/TSV spreadsheets with live data grid preview.
* [**Base64 Image Encoder & Decoder**](https://www.devomnitools.com/en/tools/base64-image/) — Drag-and-drop images into Data URIs, HTML `<img>`, CSS background, and Markdown; decode Base64 back to downloadable PNG/JPG.
* [**JSON Formatter & Validator**](https://www.devomnitools.com/en/tools/json-formatter/) — RFC 8259 syntax parsing, tree metrics, 2/4/tab formatting, 1-click minification.
* [**JSON to TypeScript Generator**](https://www.devomnitools.com/en/tools/json-to-ts/) — Recursive interface inference, optional properties, nested type resolution.
* [**YAML to JSON Converter**](https://www.devomnitools.com/en/tools/yaml-json-converter/) — Bi-directional lossless parsing between YAML and JSON schemas.
* [**Multi-Dialect SQL Formatter**](https://www.devomnitools.com/en/tools/sql-formatter/) — PostgreSQL, MySQL, SQLite, and IBM Db2 syntax beautifier.
* [**XML Formatter & Tree Inspector**](https://www.devomnitools.com/en/tools/xml-formatter/) — Indents and cleans complex XML feeds and SOAP payloads.
* [**Markdown to HTML Converter**](https://www.devomnitools.com/en/tools/markdown-html/) — Instant GFM preview with clean HTML markup output.
* [**Markdown Table Generator**](https://www.devomnitools.com/en/tools/markdown-table-generator/) — Visual spreadsheet editor exporting formatted GitHub-flavored Markdown tables.
* [**Code Minifier**](https://www.devomnitools.com/en/tools/code-minifier/) — Instant compression for HTML, CSS, and JavaScript.

### 🛡️ Security & Cryptography
* [**AES-256-GCM Encryption / Decryption**](https://www.devomnitools.com/en/tools/aes-encryption/) — PBKDF2 key derivation, random 96-bit IV, authenticated ciphertext.
* [**Bcrypt Hash & Salt Verifier**](https://www.devomnitools.com/en/tools/bcrypt-generator/) — Client-side salt calculation with adjustable work factor (4–14).
* [**JWT Decoder & Inspector**](https://www.devomnitools.com/en/tools/jwt-decoder/) — RFC 7519 3-part decoder with live token expiration countdown timer.
* [**Cryptographic Hash Generator**](https://www.devomnitools.com/en/tools/hash-generator/) — MD5, SHA-1, SHA-256, SHA-384, and SHA-512 with checksum comparator.
* [**HMAC Generator**](https://www.devomnitools.com/en/tools/hmac-generator/) — Keyed-hash message authentication code generator.
* [**Password Entropy Tester**](https://www.devomnitools.com/en/tools/password-entropy-tester/) — Mathematical zxcvbn-style entropy scoring with brute-force resistance time estimates.
* [**Content Security Policy (CSP) Builder**](https://www.devomnitools.com/en/tools/csp-header-builder/) — Interactive anti-XSS header generator with directive presets.
